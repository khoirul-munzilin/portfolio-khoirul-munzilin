# Khoirul Munzilin - Professional Portfolio

GitHub Pages-ready static portfolio. Images are stored separately in `assets/` so every file is below GitHub's browser upload limit.

## Deploy
1. Upload `index.html`, `.nojekyll`, and the complete `assets` folder to the repository root.
2. Open Settings > Pages.
3. Select Deploy from a branch, branch `main`, folder `/ (root)`.
4. Save and wait for deployment.

## Important
Do not rename, move, or omit the `assets` folder.
